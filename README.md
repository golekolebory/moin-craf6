# Minecraft.js

A minimalist Minecraft-like game built entirely with JavaScript and Three.js, running in the browser. Explore a voxel world, break blocks, and place new ones!

## Features

*   **Voxel World Generation**: Procedurally generated terrain with different block types (grass, dirt, stone).
*   **First-Person Controls**: Walk, jump, and look around using standard WASD, Space, and mouse input.
*   **Block Interaction**: Destroy blocks with the left mouse button and place blocks with the right mouse button.
*   **Basic Physics**: Gravity and collision detection with the world.
*   **Sound Effects**: Audio feedback for block placement and destruction.

## Prerequisites

To run this project, you need:

*   Node.js (LTS version recommended) and npm installed.
*   A modern web browser (Chrome, Firefox, Edge, Safari).
